# Privacy Policy

[简体中文](PRIVACY.zh-CN.md) | English

AppSentinel processes Endpoint Security events locally on the user's Mac.

- No security event data is sent to the developer or a third party.
- No file contents, credentials, browsing data, or personal information are uploaded.
- Logs remain on the local Mac and are controlled by its owner.
- Monitoring applies only to applications selected by the user and to protected locations that are part of the active security policy.

AppSentinel does not include analytics, advertising, or remote telemetry.
